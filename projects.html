Home automation platform

A family of ESP32 controllers built on one shared firmware framework and one server layer. Design rule: each device's safety function keeps working without Wi-Fi, the server or the phone.

home-idf
GitHub

Shared ESP-IDF framework for all controllers: Wi-Fi roaming, HTTPS OTA with health check and rollback, MQTT with retained state documents, push notifications, session auth and a common web app shell. Host-tested pure C modules.

C ESP-IDF
Water Controller
GitHub

Anti-flood valve controller: closes a motorised valve on abnormal flow, works offline, web app, MQTT/PostgreSQL history, OTA with rollback. In use since 2020; stopped several real leaks.
